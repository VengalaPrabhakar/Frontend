1.HTML(Hyper Text Markup Language)

HTML is used to create the basic structure of a website or web page.
It tells the browser what content should be displayed, such as headings, paragraphs, images, links, tables and forms. Simply ,HTML is a skelton of web page.

2.CSS(Cascading Style Sheet)

CSS is used to style and design HTML web pages.
It controls colours, fonts, backgrounds, spacing, borders, layouts and animations.
In simple words, CSS makes a website attractive and beautiful.

3.JAVA SCRIPT

JavaScript (JS) is a programming language used to make websites interactive and dynamic.
In simple words, JavaScript adds functionality to a website.
